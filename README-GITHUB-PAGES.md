# Subhash Portfolio — GitHub Pages Ready

This version is configured for a static Next.js export and GitHub Pages deployment.

## Run locally

```powershell
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to GitHub Pages

1. Create a public GitHub repository.
2. Upload/push the contents of this folder to the repository's `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. Push to `main` (or run the workflow manually).
6. GitHub Actions will build the static `out` folder and deploy it.

For a project repository, the site normally appears at:
`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

The portfolio includes the real project logos and the statement:
