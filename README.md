# Subhash M — Advanced Portfolio v2

A premium, responsive Next.js portfolio built from the supplied starter and redesigned as a real website (not a generated screenshot).

## Included
- Your supplied professional photo at `public/subhash-profile.jpeg`
- Resume PDF at `public/Subhash-Resume.pdf`
- Interactive project filtering
- Project detail modal
- Scroll-aware navigation
- Live Heavy Rent Go link
- Digital House Rents honest MVP engineering note
- PartyBox case study
- Skills cloud, experience timeline, education and contact CTA
- Responsive mobile navigation
- Motion, grid, glow, orbit and glass effects using CSS

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Production build
```bash
npm run build
npm start
```

## Deploy
Push this folder to GitHub and import the repository into Vercel. No environment variables are required for this portfolio.

## Important
The portfolio describes Digital House Rents as a working MVP/demo rather than a production app. This is intentional and should remain accurate until production hardening is complete.
